# Official logo asset

`av_splat.png` is the original black-and-gold splatter monogram supplied as `av_splat-g.png` in `av_splat-g.zip`. The image bytes are unchanged (SHA256: `ac0edd996e509441a94540c40f069ff115e8d6a80e57c740728fc6187120d7e1`). Splash and icon loading preserve its colors, proportions and transparency and use a light inset behind the original artwork.
